내 비서 설정

Google · 삼성 캘린더 연동

Google 계정에 저장된 일정을 연결합니다. 삼성 캘린더에서도 같은 Google 계정을 동기화하세요. 휴대폰에만 저장된 일정과 삼성 계정 전용 일정은 이 웹 연결에 포함되지 않습니다.

미연결

본인 Google Cloud 프로젝트에서 Calendar API와 웹 OAuth 설정이 필요합니다. 비밀번호·Client Secret은 입력하지 마세요. 자세한 설정은 ZIP의 README.md를 보세요.

읽기: 앞으로 90일, 페이지가 열리고 로그인된 동안 약 5분마다 갱신. 쓰기: 이 앱이 만든 일정만. 인증 토큰은 기기 메모리에만 두며, 페이지 재시작·만료 시 다시 로그인해야 합니다. 서버에서 24시간 실행되는 연결은 아닙니다.

화면 꺼짐 “자비스” 호출

웹버전에서는 지원하지 않습니다. 별도의 Android 실험 소스를 준비했습니다. 설치된 앱·음성 모델·마이크 권한·기본 비서 설정과 실기기 시험이 필요합니다. 현재 휴대폰에 설치되거나 호출이 검증된 상태가 아닙니다.

자비스 목소리

차분한 저음 프리셋입니다. 실제 남성 음색·품질은 기기에 설치된 한국어 음성에 따라 다릅니다. 유료 고급 TTS나 특정 인물의 목소리는 연결하지 않았습니다.

이 브라우저에서 가능한 기능

지원 상태를 확인 중입니다.

마이크 버튼을 눌러 시작하는 음성 인식·음성 합성·파일 저장은 브라우저별로 다릅니다. 잠금 화면 호출, 닫힌 페이지의 알림, Android 전용 API는 HTML에 포함할 수 없습니다. 브라우저/HTML 뷰어가 스크립트를 차단하면 작동하지 않습니다.

앱 설치

오프라인 준비 상태를 확인 중입니다.

웹 푸시 일정 알림

페이지를 닫아도 받을 수 있도록 서버가 알림을 발송합니다. 서버 배포·인터넷·브라우저 권한이 필요하며 절전·강제 중지 등에 따라 지연되거나 누락될 수 있습니다.

알림 서버 연결 전

연결 실패 시 이전 예약이 서버에 남아 있을 수 있습니다. 일정 변경 후 서버 동기화 상태를 확인하세요. 서버는 알림용 일정만 저장하며 다른 기기로 로컬 일정을 복원하는 기능은 아닙니다.

상시 음성 호출은 미지원

이 PWA는 화면을 끄거나 앱을 닫아둔 상태에서 “자비스”를 계속 듣지 않습니다. 기존 버튼형 1회 음성 인식만 유지합니다. 상시 호출에는 별도 안드로이드 호출 엔진·권한 설계·실기기 검증이 필요합니다.

내 일정 백업

일정은 이 브라우저의 로컬 저장소에 보관됩니다. Google·삼성 캘린더와 자동 동기화되지 않습니다. 파일 위치·브라우저 변경이나 데이터 삭제 전에 백업하세요.

가능한 요청

• 자비스 → 짧게 응답
• 오늘 / 내일 / 이번 주 일정 알려줘
• 10월 20일 오후 3시 치과 추가해줘
• 내일 오후 7시부터 8시까지 운동 추가
• 치과 일정 삭제해줘 → 목록 확인 후 삭제
• 일정 변경 → 일정 목록에서 수정

날짜·시간이 빠지면 확인창에서 입력합니다. 최종 저장 전 확인하며, 일정이 겹치면 알려드립니다.

기존 일정 재배치 · 옮겨도 되는 일정 선택

기본값은 모두 고정입니다. 이 앱에 저장된 일정 중 선택한 것만 이동 대상입니다. Google에서만 존재하는 일정·종일 일정은 옮기지 않습니다. 모두 배치할 공간이 없으면 변경하지 않습니다.
