내 비서 설정

이 브라우저에서 가능한 기능

지원 상태를 확인 중입니다.

마이크 버튼을 눌러 시작하는 음성 인식·음성 합성·파일 저장은 브라우저별로 다릅니다. 잠금 화면 호출, 닫힌 페이지의 알림, Android 전용 API는 HTML에 포함할 수 없습니다. 브라우저/HTML 뷰어가 스크립트를 차단하면 작동하지 않습니다.

설치와 알림을 설정하세요.

앱 설치

HTTPS 사이트에서 설치할 수 있습니다.

오프라인 준비 상태를 확인 중입니다.

웹 푸시 일정 알림

페이지를 닫아도 받을 수 있도록 서버가 알림을 발송합니다. 서버 배포·인터넷·브라우저 권한이 필요하며 절전·강제 중지 등에 따라 지연되거나 누락될 수 있습니다.

알림 서버 연결 전

연결 실패 시 이전 예약이 서버에 남아 있을 수 있습니다. 일정 변경 후 서버 동기화 상태를 확인하세요. 서버는 알림용 일정만 저장하며 다른 기기로 로컬 일정을 복원하는 기능은 아닙니다.

상시 음성 호출은 미지원

이 PWA는 화면을 끄거나 앱을 닫아둔 상태에서 “자비스”를 계속 듣지 않습니다. 기존 버튼형 1회 음성 인식만 유지합니다. 상시 호출에는 별도 안드로이드 호출 엔진·권한 설계·실기기 검증이 필요합니다.

내 일정 백업

일정은 이 브라우저의 로컬 저장소에 보관됩니다. Google·삼성 캘린더와 자동 동기화되지 않습니다. 파일 위치·브라우저 변경이나 데이터 삭제 전에 백업하세요.

가능한 요청

• 자비스 → 짧게 응답
• 오늘 / 내일 / 이번 주 일정 알려줘
• 10월 20일 오후 3시 치과 추가해줘
• 내일 오후 7시부터 8시까지 운동 추가
• 치과 일정 삭제해줘 → 목록 확인 후 삭제
• 일정 변경 → 일정 목록에서 수정

날짜·시간이 빠지면 확인창에서 입력합니다. 최종 저장 전 확인하며, 일정이 겹치면 알려드립니다.
